# tamreen-ai/vocab-images

Vocabulary flashcard images for the [Tamreen AI](https://github.com/tamreen-ai/tamreen-ai) Arabic learning platform.  
Served via jsDelivr CDN: `https://cdn.jsdelivr.net/gh/tamreen-ai/vocab-images@{version}/images/{filename}`

---

## Purpose

Each image is tied to a vocabulary word in At-Tareeqatul Arabiyya. Students see the image on the back of a flashcard instead of (or alongside) an English translation, reinforcing association between Arabic word and real-world concept.

---

## File Naming Convention

```
{wordId}_{english_slug}.webp
```

Examples:
```
v1_c1_l1_w1_book.webp
v1_c1_l1_w2_pen.webp
v1_c2_l3_w5_house.webp
v1_c3_l1_w1_running_man.webp
```

### wordId format

Derived from the vocabulary JSON structure:

| Segment | Meaning | Example |
|---------|---------|---------|
| `v1` | Volume 1 | At-Tareeqatul Arabiyya Part 1 |
| `c1` | Chapter 1 (الباب الأول) | |
| `l1` | Lesson 1 (الدرس الأول) | |
| `w1` | Word ID (from `words[].id` in vocab JSON) | |

### Slug rules (`english_slug`)

```
lowercase → replace non-alphanumeric runs with _ → strip leading/trailing _
```

| English | Slug |
|---------|------|
| `book` | `book` |
| `running man` | `running_man` |
| `mother-in-law` | `mother_in_law` |
| `it's` | `its` |

## Image Specifications

| Property | Requirement |
|----------|-------------|
| **Format** | WebP (primary) — JPEG allowed as fallback only |
| **Dimensions** | 400 × 400 px (square crop) |
| **File size** | Max 80 KB per image |
| **Background** | Clear, neutral (white or light grey preferred) |
| **Content** | Single subject, unambiguous |
| **Text** | No text overlay on image |
| **License** | Free for commercial use (Unsplash, Pexels, AI-generated, own photos) |
| **Cultural tone** | Appropriate for Arabic-speaking students |

## How to Add Images

1. Source image (Unsplash / Pexels / AI-generated)
2. Crop to 400×400 px, convert to WebP at ≤80 KB
3. Name the file: `{wordId}_{english_slug}.webp`
   - See `scripts/generate-word-list.js` for the full list of expected filenames
4. Drop into the `images/` folder
5. Run the manifest generator:
   ```bash
   node scripts/generate-manifest.js --version X.Y.Z
   ```
6. Commit everything and tag:
   ```bash
   git add images/ manifest.json
   git commit -m "feat: add images for batch X"
   git tag vX.Y.Z
   git push origin main --tags
   ```

---

## Tagging Workflow

The app uses **version-pinned CDN URLs** (`@vX.Y.Z`). Every commit that adds or replaces images **must** bump the version and create a tag.

Version bumping rules:
- **Patch** (`X.Y.Z+1`): adding new images, replacing existing ones
- **Minor** (`X.Y+1.0`): bulk batch addition (50+ new images)
- **Major** (`X+1.0.0`): breaking rename of existing images or wordId changes

The CDN URL for a version-pinned image:
```
https://cdn.jsdelivr.net/gh/tamreen-ai/vocab-images@vX.Y.Z/images/{wordId}_{slug}.webp
```

The manifest (always latest from main branch):
```
https://raw.githubusercontent.com/tamreen-ai/vocab-images/main/manifest.json
```

## manifest.json

Auto-generated by `scripts/generate-manifest.js`. **Do not hand-edit.**

```json
{
  "version": "1.0.0",
  "updatedAt": "2026-06-28",
  "wordIds": [
    "v1_c1_l1_w1",
    "v1_c1_l1_w2"
  ]
}
```

- `version` matches the git tag for CDN pinning
- `wordIds` is a sorted list of all word IDs that have images
- App fetches this manifest (cached in Redis 1h) to discover which words have images

## Repository Size

If the `images/` folder grows beyond ~200 MB, enable Git LFS:
```bash
git lfs install
git lfs track "images/*.webp" "images/*.jpg"
git add .gitattributes
```

`.gitattributes` is already pre-configured for LFS (see file) — just run `git lfs install` when needed.

## Scripts

| Script | Purpose |
|--------|---------|
| `scripts/generate-manifest.js` | Scan `images/`, write `manifest.json` |
| `scripts/generate-word-list.js` | Read vocab JSON, output needed filenames |

### generate-manifest.js

```bash
node scripts/generate-manifest.js --version 1.0.0
```

### generate-word-list.js

```bash
# Output to console
node scripts/generate-word-list.js

# Save to file
node scripts/generate-word-list.js > needed-images.txt

# Filter by volume
node scripts/generate-word-list.js --volume 1
```
